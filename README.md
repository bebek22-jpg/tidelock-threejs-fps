TIDELOCK is a tactical 4v4 first-person shooter on Pier 9, built with three.js: plant-and-defuse rounds, an economy with buy phases, grenades, and bots that move, see, and shoot back. An entry for make.fun's "Make the best three.js tactical FPS" bounty.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and click to play.
